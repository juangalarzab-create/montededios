⚙️ Configurar Firebase

Sigue estos pasos para activar el tiempo real y las notificaciones:

1. Crea un proyecto en Firebase
→ console.firebase.google.com → "Agregar proyecto"

2. Activa Realtime Database
→ Build → Realtime Database → Crear base de datos → Modo prueba

3. Activa Cloud Messaging (FCM)
→ Project Settings → Cloud Messaging → Genera VAPID Key

4. Obtén tu configuración
→ Project Settings → Your apps → Web app → Copia firebaseConfig

5. Edita index.html
→ Reemplaza los valores en la sección "🔧 CONFIGURA AQUÍ"

6. Agrega firebase-messaging-sw.js
→ Descarga el archivo del paquete y súbelo junto a index.html

7. Sube los archivos a hosting
→ Firebase Hosting, Netlify, o cualquier servidor HTTPS
→ ¡Las PWA solo funcionan en HTTPS!
